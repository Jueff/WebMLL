====== MobaLedLib Studio – Begriffe ======
//Seitenstand 1.10 (2026-11-27), gilt für Version 5.58//

Hier stehen die Wörter, die auf den Seiten zu MobaLedLib Studio vorkommen, in alphabetischer Reihenfolge.

^ Begriff ^ Bedeutung ^
| **Arduino** | Ein kleiner Computer (Mikrocontroller) auf einer Platine. Der **Arduino Nano** steckt in der **Lichtmaschine Classic**. |
| **Arduino IDE** | Ein Programm, mit dem man Arduino-Programme schreiben und hochladen kann. MobaLedLib Studio braucht sie nicht mehr, kann sie aber zusätzlich benutzen. Wenn doch, dann die **Version 1.8.19**, nicht 2.x. |
| **Browser** | Das Programm, mit dem du Internetseiten ansiehst: Chrome, Edge, Firefox, Safari. MobaLedLib Studio wird darin bedient. |
| **COM-Port / USB-Anschluss** | Der „Name“, unter dem der Computer die angesteckte Lichtmaschine kennt (unter Windows zum Beispiel COM5, unter Linux /dev/ttyUSB0). Das Programm sucht ihn meist selbst. |
| **Desktop** | Die Arbeitsfläche deines Computers mit den Symbolen. |
| **Direktmodus** | Eine Art der Verbindung zur Lichtmaschine: Das Programm steuert **einzelne LEDs direkt** an und ändert ihre Farbe. Benutzt im **Farb Test**, in den **Servo Einstellungen**, im **Sound Test** und bei den Makros **Servo Animation** und **LED Farb-Animation**. Siehe [[anleitungen:mobaledlibstudio:pg_arduino#die_drei_arten_der_verbindung|Die drei Arten der Verbindung]]. |
| **Effektmodus** | Eine Art der Verbindung zur Lichtmaschine: Sie arbeitet **genauso wie auf der Anlage**, alle Effekte und Makros laufen. Nötig für die **Testtasten** der Tabelle; gilt für alles, was nicht im Direktmodus arbeitet. Siehe [[anleitungen:mobaledlibstudio:pg_arduino#die_drei_arten_der_verbindung|Die drei Arten der Verbindung]]. |
| **ESP32** | Ein Mikrocontroller. Er steckt in der **Lichtmaschine Pro**. |
| **Heartbeat LED** | Die **erste LED** einer Kette. Sie sitzt bei **allen vier Lichtmaschinen fest auf der Platine** und blinkt in wechselnden Regenbogenfarben, damit man sieht, dass der **Prozessor arbeitet**. |
| **Hochladen (Upload)** | Das fertige Programm vom Computer auf die Lichtmaschine schicken. In MobaLedLib Studio heißt der Knopf **Setup übertragen**. |
| **LED RGB-Anschluss** | Ein WS2811-Modul hat **drei Ausgänge** (Rot, Grün, Blau), an die einzelne LEDs angeschlossen werden. Der **LED RGB-Anschluss** sagt, welche davon ein Makro benutzt: alle, nur zwei (Gelb = 1&2, Zyan = 2&3) oder einen einzelnen (Rot, Grün oder Blau). Im Parameterformular der Makros wählst du ihn mit den farbigen Tasten unter **LED RGB-Anschluss Auswahl** (bis 5.57 „LED Kanal Auswahl“). Nicht zu verwechseln mit dem **LM-Ausgang**. |
| **LED-Kette** | Mehrere LEDs (WS2812 oder WS2811), die hintereinander an einem einzigen Anschluss hängen. Jede LED hat eine Nummer. |
| **Lichtmaschine** | Die Steuerplatine der MobaLedLib. Sie steuert LEDs, Servos und Sound. Ihr Programm lädst du mit MobaLedLib Studio hoch. Es gibt vier: die **Lichtmaschine Classic** (mit ARDUINO Nano), die **Lichtmaschine Pro** (mit ESP32), die **Lichtmaschine Pico Zero** (mit Raspberry Pico) und die **Lichtmaschine Molli** (mit Raspberry Pico). |
| **LM-Ausgang** | Kurz für **Lichtmaschine Ausgang**: die Nummer des Ausgangs der Lichtmaschine, an dem eine **LED-Kette** hängt. Es lassen sich mehrere LED-Ketten ansteuern: **0** = normale LEDs, **1** = Taster-LEDs (Knopf Druck Aktion), **2** und **3** frei verfügbar. In der Tabelle heißt die Spalte **LM-Ausgang** (bis 5.54 „LED Kanal“ oder „LED/ Sound Kanal“), im Servo-, Sound- und Raum-Dialog gibt es das gleiche Feld. Nicht zu verwechseln mit dem **LED RGB-Anschluss**. |
| **Makro** | Eine fertige Funktion der MobaLedLib, zum Beispiel „Belebtes Haus“, „Straßenbeleuchtung“ oder „Heartbeat LED“. Du wählst ein Makro aus und stellst ein paar Werte ein. |
| **Muster (Pattern)** | Eine selbst gemachte Folge von Lichteffekten. Sie wird im [[anleitungen:mobaledlibstudio:patterngenerator|Timeline Editor]] erstellt. |
| **PlatformIO** | Ein Hilfsprogramm, das aus deiner Tabelle das Programm für die Lichtmaschine übersetzt und hochlädt. Es wird automatisch mitinstalliert. |
| **Python** | Die Programmiersprache, in der MobaLedLib Studio geschrieben ist. Du musst Python nicht kennen: Das Installationsskript prüft, ob die richtige Version da ist, und kümmert sich darum. |
| **Programmgenerator** | Die Tabelle, in der du die Makros auswählst. Hier erzeugst du das Programm für die Lichtmaschine. |
| **Raspberry Pi** | Ein kleiner, günstiger Computer. MobaLedLib Studio läuft darauf als Dauerdienst. Nicht zu verwechseln mit dem **Raspberry Pico**. |
| **Raspberry Pico** | Ein kleiner Mikrocontroller (Raspberry Pi Pico, kein Raspberry Pi). Er steckt in der **Lichtmaschine Pico Zero** und in der **Lichtmaschine Molli**. |
| **Release** | Eine fertige, veröffentlichte Version von MobaLedLib Studio auf GitHub. |
| **Setup** | Das fertige Programm für die Lichtmaschine mit allen Einstellungen aus deiner Tabelle. |
| **Skript** | Eine kleine Datei mit Befehlen, die der Computer der Reihe nach ausführt. Die Installation ist ein Skript. |
| **Terminal / Eingabeaufforderung** | Ein Fenster, in dem man Befehle eintippt. Auf Windows brauchst du es für die Installation nicht. Auf Mac, Linux und dem Raspberry Pi öffnest du es einmal für die Installation. |
| **Treiber** | Ein kleines Programm, damit der Computer ein angestecktes Gerät versteht. Bei manchen Arduino-Nachbauten (CH340) braucht Windows einen Treiber. |
| **ZIP-Datei** | Eine Datei, in der viele Dateien zusammengepackt sind. Du **entpackst** sie, um an die Dateien zu kommen. |
